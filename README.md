## 当前功能

| 端 | 使用者 | 主要功能 |
|---|---|---|
| 微信小程序 1.2.0 | 患者 | 注册登录、预约、预约金支付、退款、就诊账单、我的牙齿、治疗计划、牙位图、复查提醒 |
| Web 管理端 | 员工/管理员 | 今日工作台、患者目录、临床档案、预约与日程看板、排班、治疗方案、牙位图、召回、结算、成本、绩效、审计 |

员工端不在小程序内，统一使用 Web 管理端。

## 数据库

- MySQL：34 张实体表 + 1 个派生绩效视图
  - 22 张核心业务表
  - 8 张患者门户表
  - 4 张临床扩展表
- 小程序云数据库：25 个集合
- 临床迁移：`npm run db:migrate:clinical`

## 说明

小程序云数据库与 Web 端 MySQL 当前为独立数据域，未实现自动同步；支付与退款为模拟流程。详细限制见报告第 8 章和小程序 README。
