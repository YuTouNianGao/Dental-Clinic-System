## 端与职责

| 端 | 使用者 | 主要职责 |
|---|---|---|
| 微信小程序 | 患者 | 注册登录、预约挂号、预约金支付、退款、就诊记录、账单、档案绑定、通知 |
| Web 管理端 | 员工/管理员 | 预约、患者、排班与牙椅、登记到诊、退款、支付、结算、成本、绩效、审计 |

员工端已从小程序移出，不再提供员工登录入口或员工页面。

## 小程序

- AppID：`wxd8156d8804b96d6a`
- 云开发环境：`cloud1-d5gcycdmec1eb570f`

## 说明

当前小程序云数据库与 Web 端 MySQL 是两套独立数据域，未实现自动同步；Web 端员工控制仍以 MySQL 为业务数据源。支付与退款为模拟流程。详细限制见小程序 README 与报告第 8 章。
