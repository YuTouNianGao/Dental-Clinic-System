# SQL

本目录保存牙科连锁诊所管理系统的 MySQL 8.0 数据库结构脚本。

- `01_schema.sql`：完整数据库结构，包含 22 张实体表、1 个派生绩效视图、主键、外键、唯一约束、CHECK 约束、生成列、索引和注释。
- 目标数据库：`dental_clinic_db`。
- 已在本地 MySQL Community Server 8.0.44 上实际执行验证。
- 验证结果：22 张 InnoDB 表、1 个视图、44 个外键、26 个唯一约束、24 个 CHECK 约束、106 个不同索引。
- 脚本不包含默认账号、默认密码或虚构业务数据。
- 实际部署前仍需由项目方确认数据库账号权限、事务规则、快照不可变性和审计保留策略。
